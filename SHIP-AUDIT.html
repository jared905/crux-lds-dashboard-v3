The payload story

Where the renovation started, where it landed, and what carries the remaining weight.

Fixed3.2 MB → 147 KB first load. The original build shipped every feature up front. Today the critical path is four cached files (app, React, icons, Supabase client); all 76 feature chunks load only when their page opens.
Fixed~7 MB of invisible weight removed per client load. The dashboard's video query was downloading a 1,536-number AI embedding per video that nothing on screen reads.
FixedNightly sync: ~4,000 database round trips → 49. Batched writes; a full portfolio sync no longer risks timeouts as the client list grows.
FixedProduction console silenced. 49 debug log calls are stripped from shipping builds automatically; warnings and errors still surface for real incidents.

Code health

Bloat, dead code, and leaks

CleanZero unreferenced files. A full import-graph scan of all 210 source files found two orphans (both leftovers of removed features); deleted. 70+ dead files were removed across the renovation, including four entire retired features folded into better homes.
CleanZero unused dependencies. All 10 runtime packages are imported and load lazily where heavy.
CleanStale browser storage purged. The retired per-client theming system left cached palettes in every visitor's browser; the app now removes them on load.
CleanRetired animation and icon systems fully deleted — six keyframe sets, eight hover hooks, and all hand-drawn icon art replaced by the uniform tile system.
CleanMobile layout verified. The full dashboard was walked at phone width — responsive stacking, two-column KPI grid, and charts all hold; the one collision found (crowded chart date labels) is fixed.
FixedLint debt cleared to zero (2026‑08‑21). The 5,425 advisory warnings are gone: ~2,600 hardcoded colours converted to design tokens, dead code and unused imports removed, debug logging stripped, hook dependencies fixed or documented, and the JSX false-positive class eliminated by configuring the linter to actually understand JSX. Every rule now runs at error severity, so new debt fails the build instead of accumulating.
Data integrity

Numbers a client can be shown

The audit's standard: no metric renders unless its inputs are coherent. Where data can't support a claim, the interface says so instead of guessing.

FixedDuplicate videos across umbrella clients deduplicated — the same video was counted twice with disagreeing totals (820K vs 91K) and inflating the portfolio view.
FixedImpossible funnels blocked. Mixed data scopes once produced "585K impressions → 31.7M views" with a confident wrong diagnosis on top. The funnel now verifies its own inputs and shows an honest coverage notice instead.
FixedEngagement is format-aware. Shorts naturally run 80–97% retention, which inflated "engaged viewers"; the bar is now 85% for Shorts vs 50% for long-form, and the definition is printed on the chart.
FixedSeries Analysis intermittent breakage solved — a divide-by-zero on channels without ad-platform analytics produced broken scores; missing data now means "no claim," not a broken page.
NewOrganic-only switch. A heuristic flags likely media-buy videos (huge views, near-zero comments/likes/subs) and one toggle recomputes every dashboard number without them. Labeled as a heuristic, every flag carries its reason — and detection now reads the same engagement data on every load path, so flags can't silently vanish.
NewLaunch velocity curves. Every recent upload's first 14 days as a cumulative curve against the channel's recent normal — "is this one starting faster?" answered from the daily snapshots the sync already writes.
NewTimeline notes. Strategists can mark events ("new thumbnail style", "went weekly") directly on the Momentum chart, so the line explains its own bends. Ships with migration 114.
NewThumbnail change detection. The nightly sync now fingerprints every video's current thumbnail; a changed fingerprint dates a packaging swap — the raw material for CTR before/after analysis. Ships with migration 115.
DisclosedStudio-only metrics are named, not faked. New-vs-returning viewers and shorts→long viewer journeys aren't in YouTube's public API; the Viewers page says exactly that.
Before launch

The pre-ship checklist

Everything on this list is outside the codebase — it needs your access, not more code.

  1. Run migrations 109–116 in staging (one SQL-editor session; each self-verifies). 109/110 fix the public-access policies and the intermittent admin→viewer demotion; 111 turns on the Viewers page; 112 makes the Momentum chart's daily line real; 113 enables client networks; 114 timeline notes; 115 thumbnail change tracking; 116 lets the team correct the organic/promoted flag on individual videos. Until then those features show honest "not yet synced" states.
  2. Verify environment variables on the deploy target — Supabase keys, Google OAuth pair, token encryption key, cron secret, YOUTUBE_API_KEY (also powers the new Daily Outliers feed), and ANTHROPIC_API_KEY (one server-side key now serves the whole team — nobody needs to paste keys into their own browser). The nightly audience sync (registered, 9:00) fails closed without them.
  3. Client-document restyle — done (approved 2026‑08‑21). The PDF export and Quarterly report now ship in a print adaptation of the new brand: light paper ground, the brand type, azure/lime/peach accents tuned for white, and a footer note stating when CTR/retention data is unavailable rather than showing zero. This pass also fixed a real bug — the PDF's map capture was still keyed to the old map colors, so exported geography maps rendered dark; they now export correctly.
  4. Sanity-pass real client numbers against YouTube Studio for two or three channels after migrations land — especially watch-hours, which stay partial until analytics sync covers all channels.
Scope note: this audit covers the application code and build. The client-facing PDF/Quarterly documents joined the visual overhaul on 2026‑08‑21 after sign-off; the thumbnail archive and per-video traffic split from the expert review remain on the data roadmap — they need new collection, not refactoring.
